一个文件，一段想法，就可以开始写作。Markdown 让内容不被复杂的编辑界面打断，也让文字可以跟随你迁移。

## 从最简单的语法开始

使用 **粗体** 标记重点，用 *斜体* 表达轻微的强调。用列表整理思路，让段落保持简短。

- 先记录想法，再组织结构。
- 每篇文章只讨论一个核心问题。
- 写完之后，给自己一次删减的机会。

## 让代码也有自己的位置

```python
def write_every_day(idea):
    return f"今天想记下：{idea}"

print(write_every_day("保持好奇"))
```

行内代码也很方便，例如 `print()`。

## 一个小小的比较

| 写作方式 | 适合的时刻 |
| --- | --- |
| 随手笔记 | 捕捉尚未成形的想法 |
| 完整文章 | 讲清楚一个问题 |
| 定期回顾 | 发现长期的变化 |

更多语法可以参考 [Markdown 指南](https://www.markdownguide.org/basic-syntax/)。工具的价值，是让你更愿意开始。
